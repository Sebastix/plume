# Soft Plume

Tagline: **a lightweight android client**. Keep it lowercase.

Use the tagline on its own. Do not add supporting slogans; describe concrete features when more copy is needed.

Feather uses a rounded sky-blue feather, a lowercase wordmark, and white backgrounds in light mode. Dark mode follows Android automatically, using blue-charcoal backgrounds (`#10171C`), soft light text (`#E5EDF2`), and feather-blue actions. The selected direction is concept 02, Soft Plume. Production marks are lightweight vectors, adapted from that direction.

- Feather blue: `#79C4F2` (brand mark and decorative accents).
- Pale blue: `#F0F9FF` (subtle light-mode surfaces).
- Ink: `#293945` (text).
- Accessible action blue: `#2479A9` (links, buttons, selected controls).
- White: `#FFFFFF` (page and app backgrounds).

Use system sans-serif typography and standard Android components. Avoid decorative cards, drop shadows, and unnecessary animation. Pale brand blue is not used for small text on white.

The shared feather shape lives in `website/assets/feather.svg` and Android's `res/drawable/feather.xml`. The launcher uses a transparent vector feather without an adaptive background plate. Launchers may still normalize its shape or add their own background; themed adaptive-icon support is not provided by this plain vector. `zapstore-icon.png` is the store export.
