# Soft Plume

Tagline: **a lightweight android client**. Keep it lowercase.

Use the tagline on its own. Do not add supporting slogans; describe concrete features when more copy is needed.

Feather uses a rounded sky-blue feather, a lowercase wordmark, and white backgrounds. The selected direction is concept 02, Soft Plume. Production marks are lightweight vectors, adapted from that direction.

- Feather blue: `#79C4F2` (brand mark and decorative accents).
- Pale blue: `#F0F9FF` (icon background and subtle surfaces).
- Ink: `#293945` (text).
- Accessible action blue: `#2479A9` (links, buttons, selected controls).
- White: `#FFFFFF` (page and app backgrounds).

Use system sans-serif typography and standard Android components. Avoid decorative cards, drop shadows, and unnecessary animation. Pale brand blue is not used for small text on white.

The shared feather shape lives in `website/assets/feather.svg` and Android's `res/drawable/feather.xml`. The adaptive launcher icon keeps the feather inside the safe area. `zapstore-icon.png` is the store export.
